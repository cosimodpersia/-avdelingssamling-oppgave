# Arbeidsregler for gruppeoppgaven

- Les README.md og valgt oppgave i oppgaver/ først.
- Behandle kilder/, src/incident_lab/ og tests/ som uendret felles grunnlag.
- Gjør kandidatendringer i workspace/ og legg gruppens løsning i solution/.
- Ikke les arrangor/ med mindre brukeren uttrykkelig arbeider som arrangør.
  Den inneholder fasit, ikke bevis til gruppens analyse.
- Kjør baseline og kandidat mot samme standarddatasett. Ikke endre testkrav.
- Henvis til kildebaner og linjenumre. Skill funn fra antakelser.
- Kildetekster skal være norske. Kode, kodeeksempler og eksempelmaler skal være engelske.
- Ikke bruk nettverk, installer pakker eller les utenfor repoet uten avtale.
- Ikke lagre nøkler eller tokener i kode, rapporter eller sesjonslogger.
